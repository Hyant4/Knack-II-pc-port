# Knack II PC 移植版

这是面向 Windows 和 Linux x86-64 的非官方实验性移植项目。请使用自己提取的游戏文件，并安装支持 Vulkan 1.3 或更高版本的显卡驱动。

## 安装与启动

1. 从[发行页面](https://github.com/Hyant4/Knack-II-pc-port/releases)下载对应平台的软件包。
2. 在 Windows 上完整解压 ZIP，再运行 `Knack II.exe`。在 Linux 上运行 AppImage，并使用已提取的游戏目录。
3. 使用包含简体中文支持的版本时，点击窗口顶部的 **简中**。启动器会保存此选择，游戏语言需在设置中单独选择。
4. 选择包含 `eboot.bin`、`game.elf`、`sce_sys` 和 `sce_module` 的文件夹。
5. 点击**验证**。通过后点击**开始游戏**。

已支持的版本为美洲版 CUSA08014 01.00、01.01 和欧洲版 CUSA07670 01.01。中国版 CUSA08096 01.01 已加入实验性配置，仍需使用实际游戏文件测试启动、字幕和语音。该配置需要配套的新运行时，可识别 `data/lang/zhs` 中的简体中文游戏资源。其他可识别的 Knack II 转储，包括中国版 01.00，可以在显示兼容性提示后尝试以实验模式运行。详见 [issue #32](https://github.com/Hyant4/Knack-II-pc-port/issues/32)。

## 报告问题

在**日志与诊断**中查看错误或打开日志文件夹。报告问题时请附上错误、发生步骤、显卡型号和游戏版本，并删除日志中的个人路径。请勿上传游戏文件、固件、存档或内存转储。
