# Artefatos históricos

Este diretório preserva documentos ou patches antigos que estavam soltos na raiz. Eles não são aplicados automaticamente pelo build e não representam, por si só, o estado atual dos fontes.

- [`knack2_B2F2D_candidate.patch`](knack2_B2F2D_candidate.patch): candidato histórico preservado sem alterar seus bytes. Verifique sua base e os fontes atuais antes de tentar aplicá-lo.

Na limpeza de 22/10/2026, capturas, recortes binários de diagnóstico, relatórios avulsos e outros candidatos locais foram retirados da raiz e arquivados fora do Git, com manifesto de caminhos, tamanhos e SHA256. Fontes, testes, licenças, binários instalados, saves e histórico Git foram preservados.
